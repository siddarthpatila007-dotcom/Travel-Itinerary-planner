✈️ Travel Itinerary Planner

A simple web application that helps users plan and organize their trips in one place.

📌 About the Project

The Travel Itinerary Planner allows users to add and manage their travel plans by entering important trip details such as destination, date, activities, travel information, and notes.

This project is developed as part of a GitHub project assignment to understand the basic Git and GitHub workflow, including commits, branches, merging, and conflict resolution.

🚀 Features

- 📍 Add travel destination
- 📅 Select travel date
- 🎯 Add activities
- 🚆 Add travel details
- 📝 Add additional notes
- ✏️ Edit travel plans
- 🗑️ Delete travel plans
- 💾 Store data using Local Storage
- 🔄 Data remains available after refreshing the page

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage
- Git
- GitHub

▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in a web browser.
4. Enter your trip details.
5. Click Add Trip to create your itinerary.

💡 Example

A travel plan can contain:

- Destination: Mysore
- Date: 20 October 2026
- Activity: Visit Mysore Palace
- Travel Details: Bus – 7:00 AM
- Notes: Carry college ID

🎯 Project Objective

The main objective of this project is to create a simple and user-friendly travel planning application while gaining practical experience with GitHub collaboration and version control.
